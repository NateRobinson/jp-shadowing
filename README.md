# JP Shadowing - 日语影子跟读

基于《文化初級日本語 I》的影子跟读（シャドーイング）练习工具。

37 个对话场景，覆盖第1課到第15課，内置音频播放器，打开即用。

另有 **五十音道場**（`kana/`）：随机提取式五十音训练工具。

**在线使用：** https://www.myvibe.so/xwgu007/jp-shadow-reading-1

## 页面功能

### 课程导航

- **侧边栏** — 按课分组，37 个对话一键切换
- **前后切换** — 顶部 ← → 按钮，或 Alt+← / Alt+→ 快捷键
- **记忆进度** — 自动恢复上次学习的对话

### 音频播放器

- **播放/暂停** — 点击播放按钮或空格键
- **进度拖拽** — 点击或拖动进度条跳转
- **速度调节** — 0.5x / 0.75x / 1x / 1.25x / 1.5x
- **循环播放 (LOOP)** — 全文无限循环
- **A-B 复读** — 设定区间循环，攻克难句
- **播放计数** — 自动记录累计播放次数

### 内容切换

- **振り仮名** — 显示/隐藏假名注音
- **中文** — 显示/隐藏中文翻译

### 其他

- **明暗主题** — Dark / Light 模式切换
- **移动端适配** — 手机上完美显示
- **句子同步高亮** — 播放时自动高亮当前句子，点击句子跳转播放

## 练习方法

1. **第一遍** — 开启振り仮名和中文，0.75x 慢速播放，熟悉内容
2. **第二遍** — 关闭中文，1x 正常速度，跟着音频同步朗读（影子跟读）
3. **第三遍** — 关闭振り仮名，专注听力和汉字认读
4. **难句攻克** — 用 A-B 复读锁定不熟练的句子，反复跟读直到流畅

## 五十音道場（kana/index.html）

针对「按顺序默写没问题、随机抽取反应慢」的痛点设计的随机训练工具。

### 功能

- **认读模式** — 假名→输入罗马音，支持别拼（si/ti/tu/hu/zi/nn…）
- **回想模式** — 罗马音→心里默写假名，空格或点击大字揭示后自评（1 记得 / 2 忘了）
- **字表切换** — ひらがな / カタカナ / 浊音·半浊音 / 仅练薄弱
- **假名发音** — 答题后自动朗读（🔊 可关）；点击大字重听；全景图点击格子可发音
- **全景图** — 掌握度着色（薄弱/一般/掌握/未练），点击格子查看统计、★ 设重点高频轰炸
- **今日统计** — 每日题数、正确率、平均反应

### 方法论

1. **完全随机出牌** — 打断顺序链条记忆，强迫独立提取
2. **加权抽卡** — 出现概率与薄弱程度成正比，已掌握的字逐渐退居二线但不消失
3. **错字插队** — 答错的字隔几题再次出现，直到答对为止
4. **速度追踪** — 2.5 秒内答对才升级；「慢对」不算真掌握
5. **建议路线** — 每天 5–10 分钟：平假名刷到全绿 → 片假名 → 浊音 → 回想模式查漏
